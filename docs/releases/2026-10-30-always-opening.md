# 2026-10-30 手机端每次进入重播开屏

按站主要求，开屏独立于系统减少动态设置和网站背景动效开关。首次打开任何页面、刷新、站内返回首页、历史缓存恢复，以及把首页标签页切回前台，都会启动新一轮开屏。普通内页间导航保持原有流程。

移除等待页面脚本及图片时自动跳过开屏的超时逻辑，避免手机网络较慢时动画尚未开始就进入主页。开屏准备好后再交接首帧，仍可手动跳过或按 Escape；缺失素材会正常释放页面。原视频提供静音行内自动播放支持，被浏览器限制时保留备用玻璃动画，原声通过声音入口开启。每轮视频从零开始，避免恢复到上次播放中途。

保留背景动效偏好，不将其强行改成开启。全站预加载开屏图片，运行时重新确认开屏配置，不保存“已经播放过”的跨访问标记。非开屏浏览器测试通过显式禁用测试场景隔离，不再借助背景动效设置绕过开屏。

验证覆盖手机与桌面的刷新、首页返回、内页直达、历史缓存、前后台切换、慢速脚本及图片、自动播放被拒绝、素材失败、原声与背景音乐互斥、手动静音和登录连续性。发布使用正式 API 配置，只同步静态网页到主站及 GitHub Pages，保留旧站备份，不修改后端或数据库。
