Authentication endpoints:
- GET /auth/config -> {registration:"edu",deliveryMode:"local"|"smtp",devMailbox:boolean}. No secrets/admin list.
- POST /auth/request-code {email} -> {challengeId,expiresIn:600,resendAfter:60,deliveryMode:"local"|"smtp"}. Accept normalized ASCII valid emails ending .edu or .edu.<two-letter-country>, allow subdomains and require institution label, reject label tricks (edu.evil.com, not-edu.com). Exact configured admin address bypasses edu requirement; no other non-edu. Do not call this verified student identity: verifies mailbox ownership only. Codes secrets-generated six digits, HMAC stored bound to challenge/email, expire10min, latest challenge supersedes prior, one-time consumption. Cooldown60s peremail, max3/email/hour,10/peer/hour,100/day global issuance; limit verification5/challenge plus20/peer/10min and10/email/10min, persisted. Generic eligible-email responses prevent existing-account enumeration. Failed SMTP invalidates challenge. TLS/SSL certificate verification, bounded network timeout, stdlib SMTP acceptable.
- POST /auth/verify {challengeId,code,nickname?} -> {token,expiresAt,user:{id,nickname,email,role:"user"|"admin"}}. Nickname optional max40 default "A visitor"; verified existing users keep their nickname, newly registered use supplied one. Atomic verify/consume/create/session, no double consume race. Emails private; never OTP or token logs/raw storage. Session expiry/revocation and role from server persisted user/config. GET /auth/me bearer -> {user,expiresAt}. POST /auth/logout {} bearer -> 204.
- Development mailbox GET /dev/mailbox?email=... -> {messages:[{email,code,createdAt}]} only if explicitly enabled dev mailbox, development true, trusted-proxy false, immediate peer loopback, Host localhost/127.0.0.1 and local Origin if present. Production route404, reject incompatible dev/proxy config at startup. File outbox chmod600, bounded/prune; dev helper entirely absent/404 production. No code included in normal auth responses. Env PORTAL_DEV_MAILBOX=1, PORTAL_MAIL_MODE=file, PORTAL_OUTBOX_PATH for preview. Local default closed unless configured.
